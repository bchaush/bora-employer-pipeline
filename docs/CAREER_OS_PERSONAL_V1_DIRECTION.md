## Purpose

Career OS Personal V1 is:
1. Bora's personal evidence-controlled job-search operating system for immediate real use.
2. A real BUILD → VERIFY → OPERATE proof-of-work case study for Reliable AI-Enabled Business Systems.

It is not a commercial Simplify competitor, mass auto-apply product, proprietary job board, multi-agent research platform, or SaaS business.

## Product Promise

Help Bora find, verify, evaluate and prioritize real jobs, then turn only jobs Bora explicitly chooses to PURSUE into truthful Gold-standard application packages with substantially less repetitive work.

## Canonical Product Loop

```text
discovery: Gmail / URL / screenshot / existing job source
→ durable DiscoveryLead
→ exact employer/opportunity identity
→ dedupe
→ canonical gates
→ Match Truth
→ Bora review
→ PURSUE / WATCH / REJECT
→ Gold package only after current-role PURSUE
→ Bora manually submits
→ exact application/outcome tracked
```

## Differentiated Layer

Career OS owns:
- Employer Truth
- Candidate Truth / Evidence / Claims
- Match Truth
- Pursuit Truth
- Package Truth
- Application / Outcome Truth

External products remain commodity helpers:
- LinkedIn / Handshake / Simplify / employer sites may discover jobs.
- Browser tooling may assist repetitive form filling.
- External discovery IDs never become employer truth without canonical verification.

## Permanent Human Gates

1. PURSUE — required before meaningful application-package work.
2. SUBMIT — external submission remains human-controlled.

No package before current-role PURSUE.
No automatic external submission.
